## Meus projetos

### [PDV Otimizado](https://github.com/mubelesa/pdvotimizado)

Projeto autoral inspirado na minha experiência trabalhando no caixa de uma farmácia. A interface calcula o troco e sugere ajustes no pagamento para facilitar sua devolução quando faltam moedas e notas pequenas.

O projeto reúne lógica de programação, cálculos monetários e interação com interfaces usando JavaScript, HTML e CSS.

### [Casa em Ordem — Inventário residencial](https://github.com/mubelesa/inventario-residencial)

Projeto experimental para organizar objetos por cômodo e caixa e acompanhar sua conferência durante uma mudança. Inclui busca, filtros, backup e exportação do inventário em PDF.

A versão web permite explorar os fluxos de organização e conferência. Pretendo desenvolver uma versão nativa para Android após validar a proposta.

### [Formulário com consulta de CEP](https://github.com/mubelesa/formulario-cep)

Atividade de estudo realizada na EBAC, com consulta à API ViaCEP para preencher automaticamente os campos de endereço.

O projeto aplica consultas assíncronas em JavaScript, tratamento de erros, validação e armazenamento de dados no navegador.
